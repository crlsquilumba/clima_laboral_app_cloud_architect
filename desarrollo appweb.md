# PLANIFICACIÓN DESARROLLO APP WEB - CLIMA LABORAL (RRHH)

## RESUMEN EJECUTIVO

**Aplicación:** Aplicación Web de Clima Laboral para RRHH
**Duración Total:** 70 días laborables (14 semanas)
**Equipo:** 5 personas
**Metodología:** Desarrollo incremental por fases

---

## FASES DE DESARROLLO

### **FASE 1: FUNCIONALIDADES CRÍTICAS (MVP)**
**Duración:** 8-9 semanas = **40-45 días laborables**

**Sprint 1-2 (10 días):**
- **US001:** Dashboard principal con métricas
- **US005:** Gestión básica de empleados
- **US006:** Organización departamental básica

**Sprint 3-4 (10 días):**
- **US002:** Crear encuestas con IA
- **US003:** Gestión de historial de encuestas
- **US007:** Asignación de roles básicos

**Sprint 5-6 (10 días):**
- **US009:** Panel de sugerencias recibidas
- **US010:** Gestión de estados de sugerencias

**Sprint 7-8 (10-15 días):**
- **US011:** Reportes por departamento básicos
- **US016:** Configuración de notificaciones básicas

---

### **FASE 2: FUNCIONALIDADES IMPORTANTES**
**Duración:** 4-5 semanas = **20-25 días laborables**

**Sprint 9-10 (10 días):**
- **US004:** Plantillas de encuesta
- **US008:** Importación masiva de usuarios

**Sprint 11-12 (10-15 días):**
- **US012:** Análisis de tendencias temporales
- **US013:** Comparativas entre períodos

---

### **FASE 3: FUNCIONALIDADES DE SOPORTE**
**Duración:** 1-2 semanas = **5-10 días laborables**

**Sprint 13-14 (5-10 días):**
- **US014:** Exportación de datos y gráficos
- **US015:** Configuración de parámetros generales

---

## EQUIPO DE DESARROLLO

### **ROLES TÉCNICOS:**

#### **1. DESARROLLADOR SENIOR FULL-STACK (1 persona)**
**Responsabilidades:**
- Arquitectura de la aplicación web
- Desarrollo de APIs y backend
- Integración con sistemas existentes
- Integración con servicios de IA
- Code review y mentoring

**Tiempo:** 100% del proyecto
**Esfuerzo:** 70 días laborables

#### **2. DESARROLLADOR FRONTEND SENIOR (1 persona)**
**Responsabilidades:**
- Desarrollo principal de la interfaz web
- Implementación de dashboards y reportes
- Optimización de UX/UI
- Testing de funcionalidades web

**Tiempo:** 100% del proyecto
**Esfuerzo:** 70 días laborables

#### **3. DESARROLLADOR BACKEND/MIDDLEWARE (1 persona)**
**Responsabilidades:**
- Desarrollo de APIs específicas
- Integración con servicios de IA
- Gestión de base de datos
- Lógica de negocio compleja

**Tiempo:** 100% del proyecto
**Esfuerzo:** 70 días laborables

#### **4. DESARROLLADOR FULL-STACK JUNIOR/MID (1 persona)**
**Responsabilidades:**
- Desarrollo de funcionalidades simples
- Testing y debugging
- Documentación técnica
- Soporte al equipo senior

**Tiempo:** 100% del proyecto
**Esfuerzo:** 70 días laborables

### **ROLES DE SOPORTE:**

#### **5. QA/TESTER WEB (1 persona)**
**Responsabilidades:**
- Testing de funcionalidades web
- Testing de integración con IA
- Validación de UX/UI
- Testing de reportes y dashboards

**Tiempo:** 80% del proyecto
**Esfuerzo:** 56 días laborables
